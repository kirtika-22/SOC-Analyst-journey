# Day 17 - SOC Interview Revision & SIEM Basics

## Objective
Revise common SOC Analyst interview concepts and understand SIEM fundamentals.

## Topics Covered

### SOC Interview Revision
- Cybersecurity fundamentals.
- Importance of networking knowledge.
- Role of logs in investigations.
- SIEM concepts.

### SIEM vs Syslog
- Syslog is a protocol used to send and receive log messages.
- SIEM collects, correlates, analyzes, and monitors logs.

### Event IDs
- Windows Event IDs help identify suspicious activities.
- Used during SOC investigations.

### Threat Intelligence
- Validate IPs and domains using:
  - VirusTotal
  - AbuseIPDB
  - Shodan

### Linux in SOC
- Linux command line helps investigate logs.
- Used for troubleshooting and security analysis.

### SIEM Investigation Workflow
1. Alert generated.
2. Investigate logs.
3. Verify Threat Intelligence.
4. Correlate events.
5. Determine if activity is malicious.
6. Escalate or close the incident.

## Tools Mentioned
- SIEM
- Syslog
- Splunk
- VirusTotal
- AbuseIPDB
- Shodan

## Key Takeaways
- Networking fundamentals are essential for SOC Analysts.
- Logs are the backbone of security investigations.
- SIEM helps centralize and analyze logs.
- Threat Intelligence provides context during investigations.
- Linux skills improve investigation efficiency.
