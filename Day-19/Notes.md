# Day 19 - Threat Intelligence Tools & Platforms

# 1. AlienVault OTX

## Purpose
- Community-based threat intelligence sharing platform
- Used for IOC investigation and reputation checking

## Example Use Case
SOC analyst receives a suspicious IP address and checks OTX to verify if it is malicious.

## SOC Usage
- IOC enrichment
- Threat hunting
- Alert investigation
